# Lumière Salon & Spa

This template includes separate Vite and native Next.js frontends, an Express/MongoDB API, and a buyer guide.

- [Vite app](./Luxury-salon-booking/README.md)
- [Next.js app](./nextjs/README.md)
- [Backend API setup](./backend/README.md)
- [Buyer guide](./docs/buyer-guide.md)

Both frontends use the same API and support client appointment requests plus an admin dashboard. API authorization—not frontend redirects—protects client and admin data.
