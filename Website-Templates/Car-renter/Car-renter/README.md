# Voltigo Rental + Logistics

A responsive vehicle-rental experience built with React and Vite. It includes a rental landing page, filterable fleet, booking and checkout flow, and sign-in and account creation screens.

## Development

```sh
npm install
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```

The app uses `/`, `/fleet`, `/book`, `/checkout`, `/login`, and `/signup` routes. Vehicle photography is loaded from Unsplash. Checkout is a front-end demo and does not process payments.
