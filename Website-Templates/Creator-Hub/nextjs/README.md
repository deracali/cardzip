# CreatorHub — Next.js

This is the Next.js, TypeScript, and Tailwind CSS version of the CreatorHub React site. The original experience, styles, and public assets are retained to preserve the existing design and interactions.

## Run locally

```sh
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Run `npm run build` for a production build and `npm run typecheck` to check the TypeScript app-router files.

## Pages

The app has separate routes for `/`, `/login`, `/signup`, and `/maya-chen`.

The authentication forms are front-end previews and do not create accounts or process payments.
