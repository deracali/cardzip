# Saasapp Admin

A responsive SaaS admin console built with React and Vite. It includes a dashboard, analytics, user management, billing, system logs, workspace settings, sign-in/sign-up screens, and an in-app demo checkout.

## Run locally

```sh
npm install
npm run dev
```

## Available routes

- `/dashboard`
- `/analytics`
- `/users`
- `/billing`
- `/system-logs`
- `/settings`
- `/activity`
- `/checkout`
- `/login`
- `/signup`

The interface uses sample data and local interactions. Authentication and the checkout are demos; no payment processor is connected, no payment is charged, and card details are not stored.
