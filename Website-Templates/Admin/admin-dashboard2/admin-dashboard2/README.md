# NeonForge AI control plane

A responsive React and Vite dashboard for model consumption, prompt experiments, knowledge documents, audit events, API keys, workspaces, and billing.

## Development

```sh
npm install
npm run dev
```

## Validation

```sh
npm run lint
npm run build
```

This dashboard is a frontend preview. Model requests, document indexing, key management, workspace administration, and payment processing require connected backend services. The checkout page intentionally does not collect payment details or claim to charge a customer.
