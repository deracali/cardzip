# Remote.ly — Vite frontend

React + Vite frontend for the Remote Talent Hub. From this folder, install dependencies and start the development server with `npm install` and `npm run dev`. Configure `VITE_API_URL` in `.env` when the API is not at `http://localhost:5000/api`.

The complete stack setup, API contract, account roles, and payment limitations are documented in the [project README](../README.md).

Main routes include `/jobs`, `/jobs/:jobId`, `/apply/:jobId`, `/talent`, `/post-job`, `/pricing`, `/checkout`, `/login`, `/signup`, `/dashboard`, and `/admin`.

Use `npm run lint` and `npm run build` before deployment.
