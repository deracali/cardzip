# Carewell Doctor Booking - React + Vite

Carewell is a doctor directory and appointment-request template with provider profiles, specialty and location filters, appointment selection, patient sign-up, and confirmation screens.

## Run locally

```powershell
npm install
npm run dev
```

Visit the Vite URL printed in the terminal. Open `/admin` for the localStorage operations demo. Its demo login does not authenticate securely and must not be used for real patient or provider administration.

The Vite edition stores demo appointment requests and admin edits in the current browser only. It does not connect to MongoDB, authenticate patient accounts, or process payments. For the connected experience and setup details, see the [buyer guide](../docs/CARDZIP-DOCTOR-BOOKING-BUYER-GUIDE.pdf).
