# PulseLive Event Hub

A responsive event discovery and ticket-booking frontend built with React and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Pages

- `/` event discovery and featured events
- `/events` searchable, filterable event listings
- `/events/:slug` event details and ticket links
- `/schedule` conference agenda and saved sessions
- `/checkout/:slug` ticket selection and demo checkout
- `/host` event organizer inquiry form
- `/about` PulseLive overview
- `/login`, `/signup`, `/forgot-password` account screens

Checkout and account forms demonstrate the UI only; they do not process payments or connect to an account service.
