# Sizzle&Smile Food Delivery

A responsive restaurant discovery and ordering experience built with React and Vite. Includes a food discovery home page, restaurant menu and cart, table reservations, order tracking, sign-in, and checkout demo.

## Development

```sh
npm install
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```

Routes include `/`, `/restaurant`, `/reserve`, `/track`, `/login`, `/signup`, and `/checkout`. Checkout is a front-end demo only and does not process payments. Food photography is loaded from Unsplash.
