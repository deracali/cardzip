# NOVA Studio

A responsive creative-agency website and client-portal preview built with React and Vite.

## Run locally

```sh
npm install
npm run dev
```

Run `npm run build` for a production build and `npm run lint` for ESLint.

## Pages

- `/` — Agency homepage, featured work, client results, and project inquiry
- `/work` — Full selected-work portfolio
- `/services` — Branding, digital, motion, and creator partnership services
- `/case-studies` — Case study directory
- `/case-studies/:projectId` — Individual project story and results
- `/about` — NOVA Studio and its independent creator collective
- `/quote` — Project brief and quote request
- `/login` — Client portal sign-in preview
- `/signup` — Client or freelancer account creation preview
- `/dashboard` — Responsive client dashboard preview

Account, social sign-in, and inquiry forms are front-end demonstrations and do not submit data to a backend. The dashboard is sample content, not a connected client account.
