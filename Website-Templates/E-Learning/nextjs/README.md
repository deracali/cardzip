# Nexara AI — Next.js

This is the Next.js, TypeScript, and Tailwind CSS version of the Nexara AI React/Vite site. The original React experience, styles, and public assets are retained to preserve the existing design and interactions.

## Run locally

```sh
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Run `npm run build` for a production build and `npm run typecheck` to check the TypeScript app-router files.

## Pages

The optional catch-all route serves the original page experience at `/`, `/features`, `/integrations`, `/pricing`, `/faq`, `/docs`, `/demo`, `/signup`, `/login`, `/contact`, `/checkout`, `/privacy`, and `/terms`.

The original forms and checkout remain front-end previews and do not create accounts or process payments.
